# Google Play — URL de eliminación de cuenta

Para **Data safety** y requisitos de cuenta, usa esta URL pública (producción):

**https://tarantulapp.com/account-deletion**

- Debe coincidir con el dominio donde está desplegada la app web (`VITE_PUBLIC_SITE_URL` en el build del frontend).
- La misma ruta existe en la app: menú → **Account** → sección **Delete account** (tras iniciar sesión).
