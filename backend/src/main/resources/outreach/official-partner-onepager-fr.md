# TarantulApp — Programme Partenaire Officiel (one-pager)

**Pour :** boutiques et distributeurs WooCommerce (mygales, proies, substrats, terrariums)  
**Offre :** **Partenaire Officiel** sur invitation — **sans frais** sur ce track  
**Paiement :** Toujours sur **votre site web** (trafic qualifié avec UTM)

---

## Ce que vous obtenez

| Avantage | Détail |
|----------|--------|
| **Vitrine dans l’app** | Page publique : `tarantulapp.com/partner/votre-marque` |
| **Découverte** | Produits dans le marketplace avec badge **Partenaire Officiel** |
| **Zéro double saisie** | **Sync** depuis votre catalogue Woo — pas d’annonces à téléverser dans l’app |
| **Checkout sur votre site** | Les keepers parcourent TarantulApp ; paiement sur **votre boutique** |
| **Handoff panier (optionnel)** | Plusieurs articles peuvent ouvrir le panier Woo avec UTM |
| **Lien pour les réseaux** | Partage de vitrine depuis l’app |

**Exemple en ligne (partenaire fondateur) :** https://tarantulapp.com/partner/monarch-reptiles

---

## Ce dont nous avons besoin

1. Boutique **WooCommerce** avec API produits **publique** (nous testons votre URL).  
2. **Autorisation** d’afficher le catalogue sélectionné et de lier vers vos URLs (one-pager à signer).  
3. **~15 min** d’appel : catégories, zones d’expédition, test panier optionnel.  
4. Garder votre **catalogue à jour** sur le site — le sync suit les changements.

Pas besoin de : compte utilisateur par SKU, photos manuelles dans l’app, ni de changer votre checkout.

---

## Fonctionnement

```
Votre WooCommerce  →  sync automatique  →  vitrine + marketplace TarantulApp
Achat            →  checkout sur votre site (avec UTM)
```

- **Partenaire Officiel** (ce programme) : invitation gratuite, catalogue miroir, checkout externe.  
- **Vendor payant** (autre track) : éleveurs qui publient manuellement dans l’app.

---

## Handoff panier (optionnel)

Si votre Woo accepte les URL `add-to-cart` standard, le panier multi-articles fonctionne. Sinon, chaque produit ouvre sur votre site — trafic toujours tagué.
